## CI 修复：Windows Build 因找不到 pnpm 启动失败

- 现象：Actions 日志 setup-node@v4 下载 Node 20 后报 `Unable to locate executable file: pnpm`。
- 根因：`.github/workflows/windows-build.yml` 中 `setup-node`（带 `cache: pnpm`）排在 `pnpm/action-setup` 之前；setup-node 的缓存检测需要先能找到 pnpm 来计算 lockfile hash，此时 PATH 上还没有 pnpm → 直接失败。
- 修复：本地提交 `40abb88`（把 Install pnpm 前置到 setup-node 之前，pnpm 9→10），已推送 origin/main，重新触发 CI。
- 备注：`node-version: 20` 会触发 GitHub Actions 的 Node 20 弃用警告（默认已用 Node 24 跑 action），暂不影响运行，后续可顺手升到 22。
- 排查插曲：日志特征（Node 20 + win32-x64）先对到了 snap-craft，但其 build.yml 用的是 Node 22 且顺序正确；最终确认报错来自 dfy-ops 的 windows-build.yml。仓库私有，无法匿名查 run 状态。
